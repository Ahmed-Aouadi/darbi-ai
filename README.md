# دَرْبي AI — منصة تعليم ذكية

واجهة عربية RTL قابلة للنشر على Vercel، مبنية باستخدام Next.js وTypeScript. تشمل رفع ملفات PDF أو TXT/MD/CSV واستخراج النص من PDF داخل المتصفح، ثم تلخيص الدرس وإنشاء اختبار وشرح مبسّط وبطاقات مراجعة باستخدام OpenAI API.

## المتطلبات
- Node.js 18.17 أو أحدث (يفضّل Node 20)
- مفتاح OpenAI API لاستخدام وظائف الذكاء الاصطناعي

## التشغيل محليًا
1. فك ضغط المشروع وافتح المجلد في الطرفية.
2. ثبّت الاعتماديات:
   ```bash
   npm install
   ```
3. انسخ `.env.example` إلى `.env.local` وأضف مفتاح API:
   ```env
   OPENAI_API_KEY=your_api_key_here
   OPENAI_MODEL=gpt-4.1-mini
   ```
4. شغّل الموقع:
   ```bash
   npm run dev
   ```
5. افتح http://localhost:3000

## النشر على Vercel
1. ارفع مجلد المشروع إلى مستودع GitHub.
2. في Vercel اختر **Add New → Project** ثم استورد المستودع.
3. أضف `OPENAI_API_KEY` من **Settings → Environment Variables**، وأضف `OPENAI_MODEL` اختياريًا.
4. اضغط **Deploy**. لا تضع المفتاح في ملفات الواجهة أو داخل الكود.

## الموجود في النسخة الحالية
- واجهة عربية متجاوبة مع الهاتف والحاسوب.
- رفع PDF واستخراج النص القابل للتحديد (لا يوجد OCR للملفات الممسوحة ضوئيًا).
- رفع TXT وMD وCSV، أو لصق نص الدرس.
- تلخيص، اختبار، شرح مبسّط، وبطاقات مراجعة من خلال API server-side.
- رسائل واضحة عند غياب مفتاح API أو حدوث خطأ.

## ما يحتاج إلى تطوير قبل الإطلاق التجاري
هذه نسخة MVP عاملة وليست منصة إنتاج مكتملة. لا تتضمن حتى الآن تسجيل حسابات، حفظ الدروس والنتائج في قاعدة بيانات، لوحة إدارة، اشتراكات أو حدود استخدام للمستخدمين. قبل فتح التسجيل العام، أضف المصادقة، وتخزينًا آمنًا، وتحديد معدل الطلبات، وحماية من إساءة الاستخدام، وسياسة خصوصية، ومراقبة تكلفة API. الملفات المرفوعة تُقرأ في المتصفح ولا تُحفظ على خادم التطبيق؛ النص الذي يرسله المستخدم إلى وظائف AI يمر عبر API ثم إلى مزود النموذج.
