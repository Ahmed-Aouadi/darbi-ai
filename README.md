# دَرْبي — منصة مراجعة دراسية تعمل دون API

واجهة تعليمية عربية RTL مبنية باستخدام Next.js وTypeScript. أدوات المراجعة الأساسية تعمل داخل المتصفح مباشرة، ولا تحتاج إلى مفتاح API أو اشتراك في خدمة ذكاء اصطناعي.

## التشغيل محليًا

يتطلب Node.js 18.17 أو أحدث (يفضّل Node 20).

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000.

## النشر على Vercel

1. استورد هذا المستودع في Vercel.
2. اترك أمر البناء الافتراضي `npm run build`.
3. اضغط Deploy. لا تحتاج إلى إضافة متغيرات بيئة أو مفاتيح API.

## الميزات

- واجهة عربية متجاوبة مع اتجاه RTL.
- إدخال نص الدرس مباشرة.
- رفع ملفات TXT وMD وCSV.
- استخراج النص من ملفات PDF التي تحتوي على نص قابل للتحديد (لا يوجد OCR للملفات الممسوحة كصور).
- إنشاء ملخصات أولية، وأسئلة إكمال، وشرح منظّم، وبطاقات مراجعة اعتمادًا على النص محليًا.
- نسخ النتائج إلى الحافظة.

## ملاحظة مهمة حول «دون API»

هذه الأدوات تعتمد على معالجة نصية محلية وقواعد بسيطة، وليست نموذج ذكاء اصطناعي توليديًا؛ لذلك قد تكون النتائج محدودة وتحتاج إلى مراجعة الطالب. لا يُرسل نص الدرس إلى خادم لمعالجته. لا تتطلب الأدوات مفتاح OpenAI أو أي تكلفة استخدام API.
