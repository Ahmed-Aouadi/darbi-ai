# سَطر — تطبيق المواصفات

المرجع المعتمد هو `docs/MASTER_SPEC.md`، ومصدر بيانات التحديات هو `content/challenges.json` و`content/tracks.json`.

## ما تم تثبيته في هذا الفرع
- استيراد التحديات العشرين والمسارات من ملفات المصدر دون تعديل أمثلة الاختبارات أو النتائج المتوقعة.
- إضافة مدقق بيانات قابل للتشغيل قبل البناء.
- إضافة مخطط قاعدة بيانات أولي وسياسات RLS في Supabase.

## التحقق محليًا
```bash
npm install
npm run validate:content
npm run build
```

## إعداد Supabase
1. أنشئ مشروع Supabase.
2. نفّذ ملف `supabase/migrations/0001_initial_schema.sql` من SQL Editor.
3. أضف متغيرات البيئة الموضحة في `.env.example`.
4. لا تضع `SUPABASE_SERVICE_ROLE_KEY` في متغير يبدأ بـ `NEXT_PUBLIC_`.

## حدود التنفيذ الحالية
استيراد البيانات والمخطط لا يعني أن تسجيل الدخول، المصحح المعزول، الدوري، الغرف أو الإجراءات الخادمية أصبحت مكتملة. يجب وصل كل جزء بالخدمات الفعلية واختباره قبل اعتباره جاهزًا للإنتاج.
